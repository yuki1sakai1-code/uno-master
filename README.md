ブラウザで今すぐ手軽に遊べる、近未来サイバーパンク調の洗練されたシングルプレイヤー向け **UNO カードゲーム** です。  
個性豊かな 3 名の AI 対戦相手（リアルタイム思考吹き出し付き）と白熱したカードバトルを楽しめます。

PC・タブレット・スマートフォンの全画面サイズおよび縦横表示に対応しており、ローカル環境でもダブルクリックするだけでインストール不要で即座にプレイ可能です。

## 🎮 今すぐ遊ぶ（起動方法）

特別な環境構築やサーバーのセットアップは一切不要です。

### 方法 1: ダブルクリックで直接開く（一番かんたん）
1. 本リポジトリをダウンロードまたは `git clone` します。
2. フォルダ内の **`index.html`** をダブルクリックして普段お使いのブラウザ（Chrome, Edge, Safari, Firefox など）で開くだけで起動します！

### 方法 2: Windows 向け自動起動スクリプト
Windows をお使いの場合、フォルダ内の **`start.bat`** をダブルクリックすると、Python ローカルサーバーまたはブラウザを自動判別して最適な環境で起動します。

### 方法 3: 開発者向けローカルサーバー
```bash
# 依存ツールの確認 & ビルド
npm run build

# ローカルサーバー起動 (例: Python)
npm start
# http://localhost:1000 にアクセス
```

## ✨ 主な特徴

### 1. 🎨 5 つの洗練されたサイバーテーマ（デザインプレビュー）
右上のパレットアイコンまたはタイトル画面のプレビューメニューから、いつでも好みの世界観に切り替えられます。

- **Neon Tokyo**: 鮮やかなシアンとネオンピンクが輝くサイバーパンク・ナイトスタイル
- **Kyoto Zen**: 和モダンな静寂を感じさせる深緑とエメラルドグリーンの空間
- **Akiba '98**: 90年代の名機 PC-98 をオマージュしたロイヤルコバルトブルー＆夕焼けグラデーション
- **Shimokita Lo-Fi**: ヴィンテージ感あふれる暖色系のレトロ・カフェスタイル
- **Roppongi Void**: 深淵のダークブラックにミニマルな輝きを放つラグジュアリースタイル

### 2. 🤖 個性豊かな 3 名の AI 対戦相手 & リアルタイム思考吹き出し
プレイヤーごとにプレイスタイルと性格が異なり、場の状況や残り手札に応じてリアルタイムに内面のつぶやき（思考吹き出し）が表示されます。

| キャラクター | 性格・特徴 | プレイスタイル |
| :--- | :--- | :--- |
| **プレイヤー A** | 直感・情熱派 | チャンスがあれば積極的に攻め込む攻撃型 |
| **プレイヤー B** | 冷静沈着なベテラン | 盤面を冷静に読み、的確に相手の足を止める守備型 |
| **プレイヤー C** | 計算高い知性派 | 確率と手札状況を計算し、リスクを避けて手堅く進める頭脳型 |

> **💭 リアルタイム思考演出**:  
> 「ここは赤で攻めるか…」「UNO間近のプレイヤーを止めないと！」「ナイスドロー！」など、戦況に連動したセリフがアバターからポップアップします。

### 3. 🎵 BGM システム & サウンド設定
対戦の没入感を高める上質な BGM を標準搭載。画面左上のコントロールから自在に操作できます。

- **収録楽曲**:
  - `Dealer's Choice`: カジノラウンジを思わせるスタイリッシュなジャズトラック（デフォルト）
  - `Tabletop Shuffle`: リズミカルで軽快なグルーヴが心地よいテーブルトップトラック
- **オーディオ機能**:
  - **クイックミュートボタン**: 画面左上のボタンから 1 タップで ON / OFF 切り替え。
  - **設定モーダル**: 楽曲の切り替え、0%〜100% の無段階音量スライダー、BGM の有効/無効化。
  - **設定の永続化**: 音量や選択した楽曲はブラウザの `localStorage` に自動保存されます。
  - **自動再生対応**: ブラウザの自動再生ポリシーに対応し、最初のクリック操作でスムーズに再生が始まります。

### 4. 📱 スマホ・タブレット・PC 完全レスポンシブ最適化
- **画面の向きを自動判別**: 横画面（Landscape）では広々としたスタジアム配置、縦画面（Portrait）では上部にアバターをすっきりと逆三角形配置。
- **動的 SVG サイバーテーブル外枠**: 解像度や縦横比に合わせて JavaScript でプログラム描画されるため、アバター・手札・ボタンに外枠が被らない美しいマージンを常に維持。
- **手札カード 1.1 倍拡大**: スマートフォンの画面でもタップしやすく、数字や記号がくっきり見えるようサイズ感を最適化。
- **思考吹き出しの干渉防止**: 縦画面でもアバター直下に吹き出しを展開し、ヘッダーメニューや他キャラクターと重なりません。

### 5. 🃏 本格的な UNO ルール完全準拠
- **カード構成**:
  - 4 色（赤・青・緑・黄）の数字カード（0〜9）
  - アクションカード（スキップ、リバース、ドロー2）
  - ワイルドカード（ワイルド、ワイルド+4）
- **UI & アクション演出**:
  - カードを配る流れるようなディールアニメーション
  - リバース発動時の方向反転エフェクト
  - ドロー2 / ドロー4 による連続ドロー演出
  - ワイルドカード選択時の直感的なカラーパレットピッカー
  - 手札残り 1 枚時の **「UNO!」宣言ボタン**（押し忘れるとペナルティでカードを引かされます！）

## 📖 ルール詳細 & カード一覧

場の一番上にあるカードと **「同じ色」** または **「同じ数字・記号」** のカードを手札から出すことができます。

| カード | 記号 / 表記 | 効果 |
| :--- | :---: | :--- |
| **数字カード** | `0` 〜 `9` | 同じ色、または同じ数字のカードの上に重ねて出せます。 |
| **スキップ** | `⊘` | 次の手番のプレイヤーを 1 回休みにします。 |
| **リバース** | `⇄` | 手番の回り順（時計回り ⇄ 反時計回り）を逆転させます。 |
| **ドロー2** | `+2` | 次のプレイヤーに山札から 2 枚カードを引かせ、そのプレイヤーの手番を飛ばします。 |
| **ワイルド** | `W` | 場に出ているカードに関係なくいつでも出せます。場の色を好きな色（赤・青・緑・黄）に変更できます。 |
| **ワイルド+4** | `+4` | 場の色を好きな色に変更し、さらに次のプレイヤーに 4 枚カードを引かせて手番を飛ばします。 |

### 特殊ルール
1. **カードが引けない・出せない時**:
   - 出せるカードがない場合は山札をクリックして 1 枚引きます。引いたカードが出せる場合はそのまま場に出せます。
2. **パス**:
   - 山札を引いた後、カードを出さない（出せない）場合は「パス」ボタンを押して手番を終了します。
3. **UNO 宣言**:
   - 自分の手札が残り **1 枚** になったら、すかさず画面中央の **「UNO!」** ボタンを押してください。
   - 宣言せずに次のターンに進むと、ペナルティとしてカードを引かされます。
4. **勝利条件**:
   - 手札のカードを誰よりも早くすべて出し切ったプレイヤーの勝利です！

## 🛠️ 開発 & ビルド

本プロジェクトは通常の静的 Web ページとして設計されています。  
スクリプトを変更した場合は、以下のコマンドでバンドルファイル `js/bundle.js` を更新できます。

### 前提条件
- Node.js (v18 以上推奨)

### コマンド
```bash
# 配布用バンドル (js/bundle.js) のビルド
npm run build

# 開発用ファイル監視 (変更を検知して自動ビルド)
npm run watch

# ローカルテスト用簡易 HTTP サーバー起動
npm start
```

## 💡 技術的なこだわり
- **Zero-Dependency at Runtime**: 実行時は外部フレームワークや重いライブラリを一切使わず、Pure JavaScript + CSS のみで高速・軽量に動作します。
- **CORS-Free Architecture**: ES Modules を単一の IIFE スクリプト（`bundle.js`）へバンドルしているため、ローカルの `file://` プロトコルによるセキュリティ制限（CORS エラー）を受けず、ダブルクリックするだけで誰でもすぐに遊べます。
- **Dynamic Geometric SVG**: レスポンシブなサイバーテーブルの外枠は、アバターやボタンの位置に合わせてベジェ曲線と直線をリアルタイムに計算・描画しています。
