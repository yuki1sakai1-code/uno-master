# UNO 2.0

ひとりで遊べる UNO 風カードゲーム。3 体の AI 相手と対戦できます。

## 遊び方

1. `index.html` をブラウザで開く（ダブルクリックで OK）
2. **GAME START** をクリック
3. 手札のカードをクリックして場に出す、または山札をクリックして 1 枚引く
4. 同色・同数字・記号でマッチしたカードだけ出せます
5. ワイルドカードは色を選んでから出します
6. 手札が 1 枚になったら **UNO!** ボタンを押しましょう
7. 手札を全部出した人の勝ち！

## ルール

| カード | 効果 |
|--------|------|
| スキップ ⊘ | 次のプレイヤーを飛ばす |
| リバース ⇄ | ターンの向きを逆にする |
| ドロー2 +2 | 次のプレイヤーが 2 枚引いてターン終了 |
| ワイルド W | 好きな色に変更 |
| ワイルド+4 | 色を選び、次のプレイヤーが 4 枚引く |
